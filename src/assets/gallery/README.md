# Fotos de trabajos (carrusel de cada servicio)

Copiá las fotos en la carpeta del servicio y listo: la página arma el carrusel sola.

| Carpeta | Página |
|---|---|
| `autos/` | `/autos` |
| `hogares/` | `/hogares` |
| `negocios/` | `/negocios` |

- Formatos: `.jpg`, `.jpeg`, `.png`, `.webp` o `.avif` (Astro las optimiza solas).
- **Orden:** el del nombre. Numerá al principio: `01-...`, `02-...`.
- **Descripción (para Google y lectores de pantalla):** sale del nombre del archivo.
  `02-auto-polarizado-negro-humo.jpg` → "Auto polarizado negro humo".
- Solo fotos reales de trabajos de Crisur (ver `PRODUCT.md`).
