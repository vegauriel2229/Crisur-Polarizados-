# Marca — Crisur Polarizados

Dejá acá los archivos de identidad visual:

| Archivo | Formato preferido | Notas |
|---|---|---|
| `logo.svg` | SVG (ideal) o PNG con fondo transparente, ≥ 1000 px de ancho | Versión principal |
| `logo-light.svg` | Ídem | Opcional: versión para fondos oscuros |
| `isotipo.svg` | Ídem | Opcional: solo el símbolo (se usa como favicon) |

Colores: pasalos en hex (ej. `#1A1A1A`) en el chat; se cargan como tokens en `src/styles/tokens.css`.
