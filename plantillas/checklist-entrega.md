# Checklist de entrega

**Proyecto:**  **Fecha:**

## Funcionamiento
- [ ] Todas las páginas cargan sin errores (consola limpia).
- [ ] Formularios probados: el mensaje llega al correo correcto.
- [ ] Links internos y externos funcionando; botón de WhatsApp/teléfono probado en el celular.
- [ ] Página 404 personalizada.

## Calidad
- [ ] Responsive verificado en celular, tablet y escritorio.
- [ ] Lighthouse mobile ≥ 90 en las 4 categorías.
- [ ] Sin contenido de prueba (lorem ipsum, imágenes placeholder).
- [ ] Ortografía revisada.

## SEO
- [ ] Title y description por página · Open Graph · favicon.
- [ ] `sitemap.xml` y `robots.txt` · sitio enviado a Google Search Console.
- [ ] Google Business Profile (si es negocio local).

## Infraestructura
- [ ] Dominio apuntando, HTTPS activo, redirección www definida.
- [ ] Variables de entorno de producción cargadas.
- [ ] Backups configurados (si hay base de datos).
- [ ] Analytics instalado (si se pidió) y aviso de privacidad/cookies si corresponde.

## Entrega al cliente
- [ ] Accesos entregados (hosting, dominio, panel, repositorio si corresponde) en un medio seguro.
- [ ] Manual de uso (`docs/manual-cliente.md`).
- [ ] Período de soporte y condiciones de mantenimiento informados por escrito.
- [ ] Factura / pago final.
