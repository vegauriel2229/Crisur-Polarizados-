2. `arquitecto` → redacta `tareas.md`: tareas chicas, cada una con archivos, requisitos que cubre, agente, dependencias y cómo se verifica.

4. Mostrame la lista y pedime la aprobación (puedo reordenar, dividir o quitar tareas).
5. Aprobado → siguiente paso: `/spec-implementar`.
